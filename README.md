# CodeAlpha - Student Grade Tracker

Java console application for managing student marks and generating a summary report.

## Features
- Add student names and marks for 5 subjects
- Calculate total and average
- Assign a grade automatically
- Display highest and lowest average
- Display class average
- Search students by name
- Uses ArrayList and OOP
- Input validation

## Requirements
- Java JDK 17 or later

## Run
```bash
javac -d out src/Student.java src/StudentGradeTracker.java
java -cp out StudentGradeTracker
```

## Grade Rules
- A+: 90 and above
- A: 80-89
- B: 70-79
- C: 60-69
- D: 50-59
- F: below 50
